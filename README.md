# DoorCalc Pro

Калькулятор стоимости межкомнатных дверей — веб-приложение (один файл, HTML+CSS+JS, без сборки и зависимостей).

## Установка на телефон

1. Откройте на телефоне в Chrome ссылку **https://nizamay.github.io/model2/**.
2. Меню программы ☰ → «📲 Установить на телефон» (или меню Chrome ⋮ → «Добавить на главный экран» / «Установить приложение»).
3. На главном экране появится значок DoorCalc — программа открывается с него, как обычное приложение, и работает без интернета.

Перенести свои цены, модели и фото с другого телефона: там ☰ → «📤 Скачать проект», файл переслать, здесь ☰ → «📂 Открыть проект».

## Запуск на компьютере

Откройте `index.html` в любом браузере (двойным кликом или через любой веб-хостинг — файл полностью самодостаточный). Установка и офлайн-работа — только при открытии с сайта.
