# assets/source — исходные материалы

Сюда собраны «сырые» исходники, загруженные вручную, чтобы не засорять корень
репозитория. Для работы приложения напрямую не используются.

- `colors_2026/` — исходные фото 27 плёнок ПВХ (пересъёмка заказчика, октябрь 2026),
  по одному файлу на цвет, название файла — название цвета в программе. Готовые образцы
  (обрезаны, растянуты на 150 × 200 мм, свет выровнен) уже лежат внутри `index.html`,
  в `DB.colorSwatches`.
- `door_models/` — фото моделей дверей (справочно, пригодится для 2D-визуализации).
- `misc_untitled.xlsx` — сторонний файл, попавший в репозиторий (нужно проверить/удалить).

Прежние фото плёнок (обработанные в `assets/colors/pvh` и сырые `.heic` в `colors_raw`)
удалены по просьбе заказчика, чтобы не путаться; в истории git они остаются.
